# The obs functions the mini-holdings fixture cannot reach, one per line, as the
# coverage report's own file key and the function's qualified name joined by "::".
#
# Every other function under src/opus_import/obs/ has to show at least one executed line
# in the run's coverage report. Being imported does not count: coverage attributes a
# function's def line to the enclosing module region, so a method that was only defined
# reports 0% in its own region and only a real call registers.
#
# The file keys are relative to the repository root, because that is where the suite is
# run from. A run started somewhere else produces keys that match none of these.
#
# A function with nothing to measure is not on this list and cannot be. When every line
# of a body is one [tool.coverage.report]'s exclude_lines removes, coverage records
# nothing for it and the check has no question to ask. In this tree that is an abstract
# method whose whole body is `raise NotImplementedError`, and a stub inside an
# `if TYPE_CHECKING:` block.
#
# Entries are grouped, and each group carries the comment that justifies it. An entry
# naming a function that did execute, or one that no longer exists, fails the suite, so
# this file cannot quietly outlive what it describes.
#
# The right first response to a new unexecuted function is to look at the sampling rather
# than to add a line here: the report is also the recorder's guide to where the fixture
# is thin.
