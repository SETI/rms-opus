.. _api_guide:

Public Web API
==============

This guide describes the public API for the Outer Planets Unified Search (OPUS) tool
of the PDS Ring-Moon Systems Node. It was produced on |today| and covers OPUS
version |release|.

The API is served from ``https://opus.pds-rings.seti.org``; every entry point below
is named relative to that host. Nothing here needs an account, a key or a session:
each request stands on its own.
