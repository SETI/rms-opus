# Apps

The server-side Python is organized into subject-area "apps", one subdirectory each.
Each app's `__init__.py` says in one line what it is for.

The developer guide describes them properly, along with how a request reaches one and
what they share: see the "The Web Application" chapter of the documentation
(`docs/dev_guide_webapp.rst`, published at
<https://rms-opus.readthedocs.io/en/latest/dev_guide_webapp.html>). It is kept there
rather than here so that there is one description to keep correct rather than two.
